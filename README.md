# Dorm Shop Distributor

Делёжка чека из магазина между жильцами общежития — без таблиц в Excel и пересчётов в уме.

Вставляешь текст кассового чека → отмечаешь, кто что берёт (или ставишь **Общак**) → получаешь суммы и CSV-отчёт.

---

## Возможности

- Парсинг чека Пятёрочки / Агроторг в привычном текстовом виде
- Разбиение позиций с количеством > 1 шт. на отдельные строки
- Таблица с чекбоксами по участникам и режимом **Общак**
- Подсветка выбранной строки для удобной разметки
- Проверка: сумма позиций должна совпадать с итогом чека
- Подсчёт долей (общие позиции делятся поровну)
- Экспорт отчёта в CSV
- Сборка в один исполняемый файл (PyInstaller)
- Тёмная тема интерфейса на PyQt6

---

## Сборка исполняемого файла

Скрипт [`build.sh`](build.sh) собирает один файл через PyInstaller (без консоли), используя [`Distributor.spec`](Distributor.spec):

```bash
chmod +x build.sh
./build.sh
```

Результат:

```text
dist/Distributor
```

Запуск:

```bash
./dist/Distributor
```

### Что делает сборка

- упаковывает приложение и зависимости в **один** исполняемый файл;
- вшивает папку `assets/` в бандл;
- не создаёт macOS `.app` (избегает конфликта onefile + windowed в PyInstaller 6/7);
- кладёт результат в `dist/Distributor`.

### Важно после сборки

| Что | Где |
|-----|-----|
| Файл `.settings` (папка отчётов) | рядом с `Distributor` |
| Правки списка людей / дефолтной папки | в `config.py`, затем **пересобери** бинарь |
| CSV-отчёты | в папку из `.settings` / кнопки **Путь CSV** |

Если менял `config.py` — снова запусти `./build.sh`, иначе в exe останется старая конфигурация.

## Как пользоваться

1. **Вставь чек** — скопируй текст из приложения банка / чека и вставь в диалог.
2. **Разметь позиции** в таблице:
   - клик по строке подсвечивает её;
   - галочки у людей — кто берёт товар;
   - **Общак** — отметить сразу всех (равная дележка).
3. **Посчитать** — покажет суммы по каждому и сохранит CSV в выбранную папку.
4. **Новый чек** — загрузить другой чек без перезапуска.
5. **Путь CSV** — выбрать папку, куда складывать отчёты.

Имя файла отчёта формируется автоматически:

```text
otchet_YYYYMMDD_HHMMSS.csv
```

## Настройка

Все основные параметры — в [`config.py`](config.py).

### Участники

```python
PEOPLE: list[str] = [
    "Ваня",
    "Леха",
    "Саня",
    "Серега",
]
```

Можно менять имена и количество людей — колонки в таблице и CSV подстроятся сами.

### Папка отчётов по умолчанию

```python
DEFAULT_REPORT_DIR = str(Path.home() / "Desktop")
```

Используется при первом запуске, если ещё нет файла `.settings`.  
Дальше путь хранится в `.settings` и меняется кнопкой **Путь CSV** в приложении.

---

## Формат CSV

Разделитель `;`, кодировка UTF-8 с BOM (удобно открывать в Excel).

| Название | Цена | Общак | Ваня | Леха | … |
|----------|------|-------|------|------|---|
| Товар    | 99,99 | нет  | 99,99 |      |   |
| Итого    | …    |       | сумма | сумма |   |

В колонках участников — доля за позицию; в строке **Итого** — сколько должен каждый.
